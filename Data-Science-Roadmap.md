# 🧠 Data Science Learning Roadmap

### Phase 1: Foundations
- Python Programming (Syntax, Data Structures, OOP).
- Environment Setup (VS Code, Jupyter Notebooks).

### Phase 2: Data Manipulation & Analysis
- **NumPy:** Numerical computing.
- **Pandas:** Data frames, cleaning, and manipulation.

### Phase 3: Visualization & Insight
- **Matplotlib/Seaborn:** Plotting and chart visualization.
- Exploratory Data Analysis (EDA) basics.

### Phase 4: Applied Projects
- Building statistical models and predictive analysis using Scikit-Learn.
